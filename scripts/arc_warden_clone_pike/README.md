# Arc Warden Clone Pike

Пика от клона для спасения оригинального Арк Вардена.

## Что умеет

- По бинду существующий клон использует готовую Hurricane Pike на владельце.
- Второй бинд вызывает Tempest Double, ждёт появления клона и затем отправляет применение пики.
- Проверяет героя, клона и доступность предмета; проблемы записывает в лог.

## Установка

1. Поместите `pika_arc_clone_pike.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone` или `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone → Settings → Spawn clone and save`.

Автор: kael'thas' (Discord: feit._.).

# Arc Warden Clone Pike (English)

Use Tempest Double's Hurricane Pike to save the original Arc Warden.

## What it does

- A bind orders an existing clone to use Hurricane Pike on its owner.
- A second bind casts Tempest Double, waits for it to appear, and then issues the Pike cast.
- Checks that the local hero is Arc Warden and reports missing clones or unavailable items in the log.

## Install

1. Place `pika_arc_clone_pike.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone` or `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone → Settings → Spawn clone and save`.
