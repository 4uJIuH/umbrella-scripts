## Что умеет

По бинду Темпест Дабл использует Hurricane Pike на оригинальном Арк Вардене. Второй бинд призывает клона, ждёт его появления и затем отправляет применение пики.

- Отдельный бинд использует готовую Hurricane Pike существующего клона на владельце
- Дополнительный бинд вызывает Tempest Double и применяет пику после появления клона
- Скрипт проверяет героя, состояние клона, доступность пики и сообщает о проблемах в логе

## Установка

1. Поместите `pika_arc_clone_pike.lua` в папку `umbrella\scripts` и перезагрузите Lua-скрипты.
2. Откройте `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone` или `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone → Settings → Spawn clone and save`.

# Arc Warden Clone Pike (English)

## What it does

A bind orders Tempest Double to cast Hurricane Pike on the original Arc Warden. A second bind summons the clone, waits for it to appear, and then issues the Pike cast.

- One bind uses a ready Hurricane Pike from an existing clone on its owner
- A second bind casts Tempest Double and uses Pike after the clone appears
- Checks the hero, clone, and Pike availability, and reports problems in the log

## Install

1. Place `pika_arc_clone_pike.lua` in `umbrella\scripts` and reload the Lua scripts.
2. Open `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone` or `Heroes → Hero List → Arc Warden → Main Settings → Utility → Save by clone → Settings → Spawn clone and save`.
