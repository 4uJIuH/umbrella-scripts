# Auto Support Buy
Покупает Smoke of Deceit, Observer Ward и Sentry Ward, когда их запас в лавке полный, и выкладывает купленное из тайника на землю у фонтана.
## Возможности
- Покупка только при полном запасе: Smoke 3, Observer 4, Sentry 8; скупает весь запас.
- Переключатели, какие предметы покупать.
- Работа с выбранной минуты игры.
- Порог золота на руках (не нетворс), ниже которого скрипт не покупает.
- Выкладывание из тайника после покупки и «Оставлять на базе» для предметов, купленных у лавки в инвентарь.
## Установка
1. Нажмите «Установить» в Script Manager или поместите `auto_support_buy.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Scripts → Auto Support Buy`.

# Auto Support Buy (English)
Buys Smoke of Deceit, Observer Ward and Sentry Ward when their shop stock is full and drops the purchased items from the stash onto the ground at the fountain.
## Features
- Buys only at full stock: Smoke 3, Observer 4, Sentry 8; takes the whole stock.
- Switches for which items to buy.
- Starts from a chosen game minute.
- Gold-on-hand threshold (not net worth) below which nothing is bought.
- Drops items from the stash after purchase, plus "Leave at base" for items bought into the inventory at the shop.
## Install
1. Click Install in Script Manager or place `auto_support_buy.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Scripts → Auto Support Buy`.
