## Что умеет

После Tempest Double клон идёт к ближайшим нейтральным кемпам (1 или 2), бьёт их в нужную минуту и после удара, если есть Hand of Midas, применяет его на один крип. Скрипт управляет только клоном, основной герой не затрагивается. Есть ручной запуск по бинду.

- Стакает 1 или 2 ближайших кемпа клоном
- Окно удара настраивается по минуте
- Hand of Midas после удара на один крип
- Ручной запуск по бинду

## Установка

1. Поместите `avto_stak.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Arc Warden → AW Helper` и включите скрипт во вкладке `Авто стак клоном`.

# Arc Warden Auto Stack (English)

## What it does

After Tempest Double, the clone goes to the nearest neutral camps (1 or 2), strikes them in the chosen minute, and after a strike applies Hand of Midas to one creep if you have it. The script controls only the clone; the main hero is not affected. A manual run is available on a bind.

- Stacks 1 or 2 nearest camps with the clone
- Strike window set by minute
- Hand of Midas on one creep after the strike
- Manual run on a bind

## Install

1. Put `avto_stak.lua` into `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Arc Warden → AW Helper` and enable the script in the `Авто стак клоном` tab.
