# Календарь

Календарь событий поверх Dota 2 с напоминаниями в меню и во время матча.

## Что умеет

- Месячная сетка с переходом между месяцами и отметками дней с событиями.
- События с датой, временем и повторами каждый день, неделю или месяц.
- Напоминания заранее и в момент события; время и звук настраиваются.
- События сохраняются в конфиге; поддерживается до 120 событий.

## Установка

1. Поместите `calendar.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → Календарь → Main → Календарь` для просмотра или `Scripts → Utility → Календарь → Main → Новое событие` для добавления.

Автор: леха ваня и виталик (Discord: mikropabalo).

# Calendar (English)

An event calendar that overlays Dota 2 and can remind you about plans in the main menu or during a match.

## What it does

- Browse a monthly grid and see which days have events.
- Create events with dates, times, and daily, weekly, or monthly recurrence.
- Receive reminders in advance or at event time, with configurable lead time and sound.
- Events are saved in the config; up to 120 events are supported.

## Install

1. Place `calendar.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Scripts → Utility → Календарь → Main → Календарь` to view events or `Scripts → Utility → Календарь → Main → Новое событие` to add one.
