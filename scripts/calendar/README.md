## Что умеет

Добавляйте события и повторяющиеся планы в календарь, открываемый как в матче, так и в главном меню. Напоминания сопровождаются звуком.

- Месячная сетка с переходом между месяцами и отметками дней с событиями
- Создание событий с датой, временем и повторами каждый день, неделю или месяц
- Напоминания заранее и в момент события; можно настроить время и звук
- События сохраняются в конфиге; поддерживается до 120 событий

## Установка

1. Поместите `calendar.lua` в папку `umbrella\scripts` и перезагрузите Lua-скрипты.
2. Откройте `Scripts → Utility → Календарь → Main → Календарь` для просмотра или `Scripts → Utility → Календарь → Main → Новое событие` для добавления.

# Календарь (English)

## What it does

Add events and recurring plans to a calendar that can be opened in a match or from the main menu. Reminders can play a sound.

- Monthly grid with month navigation and markers on days that have events
- Create events with a date, time, and daily, weekly, or monthly recurrence
- Get reminders in advance or at event time, with configurable lead time and sound
- Events are saved in the config; up to 120 events are supported

## Install

1. Place `calendar.lua` in `umbrella\scripts` and reload the Lua scripts.
2. Open `Scripts → Utility → Календарь → Main → Календарь` to view events or `Scripts → Utility → Календарь → Main → Новое событие` to add one.
