# Калории

Шуточный дневник питания для героя в Dota 2.

## Что умеет

- Отслеживает калории игровых расходников, включая Tango, фласку, манго и сыр Рошана.
- Показывает съеденные и сожжённые калории, баланс и всплывающие уведомления.
- Отличает использование предмета от пополнения бутылки и перемещения предметов.
- Позволяет задать норму калорий и поделиться итогом матча с союзниками.

## Установка

1. Поместите `calories.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → Калории → Main → Дневник питания`.

Автор: леха ваня и виталик (Discord: mikropabalo).

# Calories (English)

A tongue-in-cheek food diary for your Dota 2 hero.

## What it does

- Tracks calories from in-game consumables, including Tango, salves, Mangos, and Roshan's Cheese.
- Shows calories eaten and burned, the balance, and optional floating notifications.
- Distinguishes item use from bottle refills and item transfers.
- Set a calorie target and optionally share the match summary with allies.

## Install

1. Place `calories.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Scripts → Utility → Калории → Main → Дневник питания`.
