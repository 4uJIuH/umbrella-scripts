## Что умеет

По клавише герой разворачивается к курсору, затем применяет на себя Force Staff или Hurricane Pike. Создатель — Tommy (Discord: tommytheitguy), последнюю версию подготовил 4uJIuH (Discord: sopka11).

- Поддерживает Force Staff и Hurricane Pike
- Два режима клавиши: «По удержанию» и «По нажатию»
- В режиме «По нажатию» герой самостоятельно разворачивается и применяет предмет, прекращая попытку через 3 секунды
- Позиция курсора фиксируется в момент нажатия в одноразовом режиме

## Установка

1. Поместите `forcestaffer.lua` в папку `umbrella\scripts`.
2. Поместите <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/q-localizer-v1.0.0/_qLocalizer.lua" target="_blank" rel="noopener"><code>_qLocalizer.lua</code></a> туда же.
3. Перезагрузите Lua-скрипты.
4. Откройте `Scripts → Scripts → Force Staffer → Settings → Force Staffer`.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Force Staffer (English)

## What it does

Press the key to turn your hero toward the cursor and use Force Staff or Hurricane Pike on yourself. Created by Tommy (Discord: tommytheitguy); the latest version was prepared by 4uJIuH (Discord: sopka11).

- Supports Force Staff and Hurricane Pike
- Two key modes: While held and One press
- In One press mode, the hero turns and uses the item automatically, giving up after 3 seconds
- The cursor position is captured when you press the key in One press mode

## Install

1. Place `forcestaffer.lua` in the `umbrella\scripts` folder.
2. Place <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/q-localizer-v1.0.0/_qLocalizer.lua" target="_blank" rel="noopener"><code>_qLocalizer.lua</code></a> in the same folder.
3. Reload the Lua scripts.
4. Open `Scripts → Scripts → Force Staffer → Settings → Force Staffer`.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
