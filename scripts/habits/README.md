## Что умеет

Трекер личных привычек с отметками и сериями дней, а также игровых целей, которые скрипт отслеживает автоматически. Данные сохраняются между запусками игры.

- Список до 8 собственных привычек с ежедневными отметками и сериями
- Напоминания во время игры о неотмеченных привычках
- Игровые цели: покупка вардов, 5 денаев, не умереть до 10:00 и не простаивать дольше 2 минут
- Итоги игровых целей после матча; окно можно открыть в игре и главном меню

## Установка

1. Поместите `habits.lua` в папку `umbrella\scripts` и перезагрузите Lua-скрипты.
2. Откройте `Scripts → Utility → Трекер привычек → Main → Привычки`.

# Трекер привычек (English)

## What it does

Tracks personal habits with daily check-offs and streaks, along with in-game goals monitored automatically. Data is saved between game sessions.

- Track up to 8 custom habits with daily check-offs and streaks
- Get in-game reminders for habits that are not checked off
- Optional game goals: buy wards, deny 5 creeps, avoid dying before 10:00, and avoid standing idle for over 2 minutes
- Review game-goal results after the match; open the tracker in a match or the Dota 2 main menu

## Install

1. Place `habits.lua` in `umbrella\scripts` and reload the Lua scripts.
2. Open `Scripts → Utility → Трекер привычек → Main → Привычки`.
