# Трекер привычек

Отмечайте личные привычки и отслеживайте игровые цели прямо в Dota 2.

## Что умеет

- Список до 8 собственных привычек с ежедневными отметками и сериями.
- Напоминания во время игры о неотмеченных привычках.
- Игровые цели: купить варды, заденаить 5 крипов, не умереть до 10:00 и не простаивать дольше 2 минут.
- Итоги игровых целей после матча; окно можно открыть и в главном меню Dota 2.
- Данные сохраняются между сессиями.

## Установка

1. Поместите `habits.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → Трекер привычек → Main → Привычки`.

Автор: леха ваня и виталик (Discord: mikropabalo).

# Habit Tracker (English)

Track personal habits and optional in-game goals, with daily check-offs and streaks.

## What it does

- Track up to 8 custom habits and build daily streaks.
- Get in-game reminders for habits that have not been checked off.
- Optionally track buying wards, denying 5 creeps, surviving until 10:00, and avoiding more than 2 minutes of inactivity.
- Review in-game goal results after the match; open the tracker from a match or the Dota 2 main menu.
- Data is saved between sessions.

## Install

1. Place `habits.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Scripts → Utility → Трекер привычек → Main → Привычки`.
