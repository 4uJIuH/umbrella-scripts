## Что умеет

Muerta использует Dead Shot через дерево, чтобы рикошетом попасть в Techies и наложить страх. Ждёт сигнала Blast Off или перехватывает героя в полёте, сам выбирает дерево и рассчитывает упреждение с учётом дальности, поворота и пути пули. Срабатывание зависит от данных о Techies и времени рикошета; если герой появляется из тумана или далеко от дерева, перехват может не успеть. Гарантированного прерывания любого прыжка из тумана нет.

- Выбирает дерево и рассчитывает упреждение Dead Shot
- Реагирует на Blast Off или перехватывает героя в полёте
- Учитывает дальность, поворот, путь пули и время каста с модификаторами

## Установка

1. Поместите `muerta_anti_techies.lua` в папку `umbrella\scripts`.
2. Нажмите Reload Scripts.
3. Откройте `Scripts → Other → muerta_anti_techies → Защита → Blast Off` и включите скрипт.
4. Выберите Muerta, изучите Dead Shot, держите Q готовым и достаточно маны.

# Muerta Anti Techies (English)

## What it does

Muerta uses Dead Shot through a tree to ricochet into Techies and apply fear. It waits for the Blast Off signal or intercepts the hero in flight, picks the tree itself, and calculates lead from range, turn, bullet path and cast time with modifiers. Triggering depends on available Techies data and ricochet timing; a hero appearing late from fog or far from the tree may not be intercepted in time. A guaranteed interruption of any jump from fog is not claimed.

- Chooses the tree and calculates the Dead Shot lead
- Responds to Blast Off or intercepts the hero in flight
- Accounts for range, turn, bullet path and cast time with modifiers

## Install

1. Put `muerta_anti_techies.lua` into `umbrella\scripts`.
2. Click Reload Scripts.
3. Open `Scripts → Other → muerta_anti_techies → Защита → Blast Off` and enable the script.
4. Select Muerta, learn Dead Shot, keep Q ready and have enough mana.
