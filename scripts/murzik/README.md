# Murzik Kitty Widget

котик-компаньон в углу экрана / a little cat companion in the corner of the screen

## Что умеет

- Настройка имени, размера, прозрачности, положения и оформления котика.
- Можно выбрать язык и разговорчивость, нажимать на котика и пользоваться меню действий.
- Кнопки `Test: kill` и `Test: death` показывают задуманные реакции.
- Известная проблема: автоматические реакции на убийства и смерти пока могут не срабатывать.

## Установка

1. Поместите `murzik.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → Kitty Widget → Kitty → Main` или `General → Main → Kitty Widget → Look → Widget`.

Автор: mamin_paren (Discord: hakerskiyfrancuskiy).

# Murzik Kitty Widget (English)

## What it does

An interactive cat overlay for Dota 2. You can rename it, change its appearance, click it, and use its action menu.

- Customize the cat's name, size, opacity, position, and appearance.
- Choose its language and chattiness.
- Use the `Test: kill` and `Test: death` buttons to preview those reactions.
- Known issue: automatic reactions to kills and deaths may not trigger yet.

## Install

1. Place `murzik.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `General → Main → Kitty Widget → Kitty → Main` or `General → Main → Kitty Widget → Look → Widget`.
