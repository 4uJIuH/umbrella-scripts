# Old Last Match

возвращает старый экран последнего матча в главное меню / restores the old last-match screen in the main menu

## Что умеет

Меняет фон главного меню с текущего события на экран последнего матча.

- Включается в General → Visuals → Old Last Match
- Не требует дополнительных библиотек

## Установка

1. Поместите `old_match.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Включите настройку в General → Visuals → Old Last Match.

# Old Last Match (English)

## What it does

Replaces the current event background on the main menu with the last-match screen.

- Toggle it under General → Visuals → Old Last Match
- No additional libraries required

## Install

1. Place `old_match.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Enable General → Visuals → Old Last Match.
