# PT Mana Abuse (ctx)

автоматически переключает Power Treads на интеллект для каста / switches Power Treads to Intelligence when needed to cast

## Что умеет

- Переключает Power Treads на интеллект, если этого хватает для применения способности.
- Учитывает дополнительную ману от PT при отображении иконок способностей.
- Локализация встроена в файл; отдельный `_qLocalizer.lua` не требуется.

## Установка

1. Поместите `pt_mana_abuse_ctx.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → PT Abuse → Settings → Основное`.

Автор: ctx (Discord: papagdetto).

# PT Mana Abuse (ctx) (English)

## What it does

- Switches Power Treads to Intelligence when that makes a spell castable.
- Accounts for Intelligence Treads mana when displaying ability icons.
- Localization is included in the file; no separate `_qLocalizer.lua` is required.

## Install

1. Place `pt_mana_abuse_ctx.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `General → Main → PT Abuse → Settings → Main`.

Author: ctx (Discord: papagdetto).
