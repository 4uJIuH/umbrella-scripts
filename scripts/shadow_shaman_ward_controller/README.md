## Что умеет

Модифицированный контроллер, адаптированный для Serpent Wards Shadow Shaman. Создатель: Tommy (Discord: tommytheitguy).

- Автоматически выбирает цель для подконтрольных Serpent Wards
- В первую очередь атакует Healing Ward Juggernaut и курьера, затем выбирает героя с наименьшим здоровьем
- Учитывает увеличенную дальность атаки от таланта

## Установка

1. Поместите `shadow_shaman_ward_controller.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Shadow Shaman → Main Settings → Ward Settings`.

# Shadow Shaman Ward Controller (English)

## What it does

A modified ward controller adapted for Shadow Shaman Serpent Wards. Created by Tommy (Discord: tommytheitguy).

- Automatically selects a target for controllable Serpent Wards
- Prioritizes Juggernaut's Healing Ward and couriers, then picks the lowest-health hero
- Accounts for the increased attack range from a talent

## Install

1. Place `shadow_shaman_ward_controller.lua` in the `umbrella\scripts` folder.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Shadow Shaman → Main Settings → Ward Settings`.
