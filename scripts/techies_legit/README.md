## Что умеет

Ставит мины Techies по случайному разбросу и с настраиваемой задержкой, интервалом и радиусом. Можно включить автокаст на точке или на цели. Случайный разброс можно отключить.

- Случайный разброс мин и задержка
- Настройка начала, радиуса и интервала установки
- Автокаст на точке или на цели

## Установка

1. Поместите `techies_legit.lua` и `!_qLocalizer.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Techies` и включите скрипт в `Main Settings`.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Techies Legit (English)

## What it does

Places Techies mines with randomized scatter and a random delay, with adjustable start time, radius and interval. Autocast can target a point or a target. The randomized scatter can be turned off.

- Randomized mine scatter and delay
- Adjustable start time, radius and interval
- Autocast on a point or on a target

## Install

1. Put `techies_legit.lua` and `!_qLocalizer.lua` into `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Techies` and enable the script in `Main Settings`.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
