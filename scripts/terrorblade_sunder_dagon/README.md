## Что умеет

Запускает комбо Terrorblade: Sunder, затем при включённой настройке Ethereal Blade и Dagon. Рассчитывает, может ли комбо убить цель, и поддерживает автоматический поиск подходящего противника. Автор: Сельский будильник (Discord: luas0726).

- Комбо по клавише и отдельный режим автокаста по цели в радиусе Sunder
- Режим «Только если можно убить» с расчётом урона
- Опциональное использование Ethereal Blade перед Dagon
- Индикатор оценки комбо, радиуса Sunder и области Radiance у врагов

В предоставленном исходнике нет применения предмета невидимости — для атаки из инвиза используйте его отдельно.

## Установка

1. Поместите `terrorblade_sunder_dagon.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Terrorblade → Sunder + Dagon`.

# Terrorblade Sunder + Dagon (English)

## What it does

Runs a Terrorblade combo: Sunder, followed by Ethereal Blade when enabled and then Dagon. It estimates whether the combo can kill the target and can automatically find a suitable enemy. Author: Сельский будильник (Discord: luas0726).

- Combo key and a separate autocast mode for targets in Sunder range
- Only if killable mode with damage estimation
- Optional Ethereal Blade before Dagon
- Indicators for combo estimate, Sunder range, and enemy Radiance radius

The supplied source does not use an invisibility item; activate invisibility separately if desired.

## Install

1. Place `terrorblade_sunder_dagon.lua` in the `umbrella\scripts` folder.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Terrorblade → Sunder + Dagon`.
