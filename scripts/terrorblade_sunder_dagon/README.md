## Что умеет

Запускает комбо Terrorblade: Sunder, затем при включённой настройке Ethereal Blade и Dagon. Рассчитывает, может ли комбо убить цель, и поддерживает авто-каст по подходящему врагу. В исходнике нет применения предмета невидимости — для атаки из инвиза используйте его отдельно. Автор: Сельский будильник (Discord: luas0726).

- Комбо по клавише и отдельный режим автоматического применения Sunder в радиусе
- Расчёт урона для безопасного режима «Только если можно убить»
- Опциональное использование Ethereal Blade перед Dagon
- Индикатор оценки комбо, радиус Sunder и область действия Radiance у врагов

## Установка

1. Поместите `terrorblade_sunder_dagon.lua` в папку `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Terrorblade → Sunder + Dagon`.

# Terrorblade Sunder + Dagon (English)

## What it does

Runs a Terrorblade combo: Sunder, followed by Ethereal Blade when enabled and then Dagon. It estimates whether the combo can kill the target and supports autocast on a suitable enemy. The supplied source does not use an invisibility item; activate invisibility separately if desired. Author: Сельский будильник (Discord: luas0726).

- Combo key plus a separate automatic Sunder mode for targets in range
- Damage estimate for the Only if killable safe mode
- Optional Ethereal Blade before Dagon
- Combo estimate indicator, Sunder range, and enemy Radiance radius

## Install

1. Place `terrorblade_sunder_dagon.lua` in the `umbrella\scripts` folder.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Terrorblade → Sunder + Dagon`.
